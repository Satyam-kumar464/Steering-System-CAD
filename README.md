# Steering System Assembly

## Overview

This project presents a conceptual steering system assembly designed and modeled in SolidWorks for educational and CAD practice purposes. The assembly includes a steering wheel, steering shaft, universal joints, steering gearbox, and tie rods that transmit driver input to the steering linkage.

The project focuses on assembly design, component integration, motion visualization, and steering system packaging commonly used in automotive applications.

## Steering Geometry

The steering layout was developed following the basic principles of the Ackermann Steering Geometry, which helps the inner and outer wheels follow different turning radii during cornering. This reduces tire scrub and improves cornering efficiency.

**Note:** The dimensions and linkage lengths used in this model are approximate and intended for conceptual design purposes. Detailed Ackermann calculations, steering ratio analysis, and dynamic validation were not performed in this version.

## Design Objectives

- Develop a functional steering system assembly
- Understand steering linkage mechanisms
- Practice CAD assembly and mating techniques
- Visualize steering motion and component interaction
- Study the fundamentals of Ackermann steering geometry
